## Stack utilizada

Este blog foi construído com as seguintes tecnologias:

### Frontend
- **Astro 7** - Framework estático moderno
- **TypeScript** - Type safety
- **CSS Variables** - Sistema de cores customizado

### Design
- **JetBrains Mono** - Fonte monoespaçada
- **Tema Terminal** - Estética inspirada em terminais Linux

### Infraestrutura
- **GitHub** - Versionamento de código
- **Vercel** - Deploy e hospedagem
- **Domínio** - duzeradev.com.br

### Features
- Sistema de posts com Astro Content Collections
- Rotas dinâmicas
- Animações CSS
- Responsivo

Código-fonte disponível no [GitHub](https://github.com/eduardonk9999/blogDuzera).
